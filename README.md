# Milner (`.mn`)
A multi-paradigm programming language featuring a hybrid execution model, named after Robin Milner. Developed as a super-curricular academic exploration into language theory, compiler construction, and discrete mathematics.

Superficially, the language is imperative, with functional programming features and a statically typed system.

Initial implementation will use a simple virtual machine. Later development may include custom intermediate representation, native code generation, object files and linking.
